# FinMind 券商分佈分析 Skill

分析指定台股標的 (SID 或中文名稱) 的券商買賣分佈情況，包含 Top 20 券商排名、成交量佔比及常態分佈統計。

## 使用方式

```
/fm.broker.distro SID 或股票名稱
```

### 參數說明

| 參數 | 說明 | 範例 |
|------|------|------|
| SID | 股票代號 | 2330, 2317, 0050 |
| 股票名稱 | 中文股票名稱 | 台積電，鴻海，聯發科 |

## 分析內容

1. **成交量彙總**：全市場買賣超、Top 20 券商買賣超、其他券商買賣超
2. **佔比分析**：Top 20 券商成交量佔全市場比例
3. **Top 20 明細**：買進/賣出排名前 20 券商詳細資料
4. **常態分佈統計**：平均值、標準差、中位數、分佈區間
5. **股票中文名稱**：查找SID對應的中文名稱

## 資料來源

- 使用 `TaiwanStockTradingDailyReport` API (需 Sponsor  tier)
- 預設分析過去 60 天交易資料
- 使用 `TaiwanStockInfo` API

## 範例

```
/fm.broker.distro 2330
```

輸出：台積電過去 60 天的券商買賣分佈分析，包含 Top 20 券商排名與統計資料。
