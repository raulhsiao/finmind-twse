# [工作目標]
## 逐筆交易/分時明細的微觀市場資料萃取出關於個股的短線（日內）與中長線趨勢信號。
- 需要左列其一輸入才可執行工作，SID: 交易標的代號，SID_NAME:交易標的中文名稱，e.g. SID=2330, SID_NAME=台積電
- 內外盤氣勢（買賣力道指標）
- 主力大單追蹤（籌碼集中信號）
- 日內均價線（VWAP，成交量加權平均價）
- 關鍵價位的支撐與壓力（價格行為）
- 時間節點動能（開收盤效應）

# [工作方法]
## 如果使用者沒有指定日期，則自動尋找最近一個有資料的交易日，如果今日時間尚未超過 15:00 則往過去的下一個交易日選擇。
- 將此時間戳記標記於摘要輸出的結尾
## 紅色與綠色的標示原則採用台灣的習知原則，中性的資料則採用藍色標記。
## 以下是運用這些欄位可以分析出的關鍵趨勢信號，以及對應的組合條件：
- 內外盤氣勢（買賣力道指標）
	- 運用欄位：TickType、volume
	- 運作邏輯：將 TickType 為 2（主動買盤/外盤）的 volume 加總，對比 TickType 為 1（主動賣盤/內盤）的 volume。集合競價/特殊交易(TickType 為 0)不計入買盤或賣盤。
	- 趨勢信號：當「主動買盤總量」遠大於「主動賣盤總量」時，代表市場追價意願高，為短線看漲（偏多）信號；反之則為看跌（偏空）信號。
- 主力大單追蹤（籌碼集中信號）
	- 運用欄位：volume、TickType、deal_price
	- 運作邏輯：設定特定門檻過濾 volume（例如單筆成交量 > 50 或 100）。
	- 趨勢信號：若連續出現大單，且 TickType 多為 2（買盤），同時 deal_price 逐步墊高，代表主力資金正在積極「吃貨」向上點火，屬於強烈的攻擊突破信號。若大單多為賣盤且價格下跌，則暗示主力正在「出貨」。
- 日內均價線（VWAP，成交量加權平均價）
	- 運用欄位：deal_price、volume、Time
	- 運作邏輯：利用公式 $\frac{\sum(deal\_price \times volume)}{\sum volume}$ 計算出每日的動態均價線。
	- 趨勢信號：這條線是日內當沖的關鍵多空分水嶺。當最新的 deal_price 穩定運行於 VWAP 之上，屬於日內多頭趨勢；若價格跌破 VWAP 且反彈無力，則轉為空頭趨勢。
- 關鍵價位的支撐與壓力（價格行為）
	- 運用欄位：deal_price、volume
	- 運作邏輯：統計在特定 deal_price 區間累積的總 volume。
	- 趨勢信號：累積成交量最大的價格區間會形成「大量區」。若股價由下往上帶量突破此區間，該區間將轉為強支撐，發出波段起漲信號；若跌破此大量區，則形成沉重上檔壓力。
- 時間節點動能（開收盤效應）
	運用欄位：Time、volume、deal_price
	運作邏輯：特別鎖定特定 Time（例如：開盤前 15 分鐘、收盤前 5 分鐘）的價量變化。
	趨勢信號：
		- 早盤信號：開盤若出現連續大 volume 且 deal_price 走高，通常能決定當日的主旋律為強勢股。
		- 尾盤信號：若在臨近收盤時出現爆量的主動買盤（TickType=2），俗稱「尾盤拉抬」，通常暗示隔日有高機率開高，為趨勢延續信號。
- 圖表輸出：
    - 圖表規格 (3 子圖，垂直排列)
    - 子圖 1：價格與 VWAP 走勢
        - X 軸：時間 (Time)，重點式的顯示時間標籤
        - Y 軸左：價格 (元)
        - 線條：
            - 成交價：折線圖
            - VWAP：紅色實線 (VWAP = cumsum(deal_price × volume) / cumsum(volume))
            - 最終 VWAP：紅色虛線水平線
        - 標題：「{SID} {SID_NAME} 日內價格與 VWAP 走勢」
        - Hovertool 提供懸浮資訊以顯示當日欄位資料，只須應用於 HTML 輸出
    - 子圖 2：累積內外盤走勢
        - X 軸：時間 (Time)，重點式的顯示時間標籤
        - Y 軸：累積成交量 (股)
        - 圖形：
            累積買盤 (TickType=2)：紅色折線
            累積賣盤 (TickType=1)：綠色折線
            兩者間填充區域 (alpha=0.3)
        - 標題：「累積內外盤走勢」
        - Hovertool 提供懸浮資訊以顯示當日欄位資料，只須應用於 HTML 輸出
    - 子圖 3：價格分佈成交量
        - 圖表類型：水平柱狀圖
        - Y 軸：10 個價格區間（以價格區間分10組）
        - X 軸：成交量（千股）
        - 顏色：
            🟢 綠色 = 支撐區（低於最大量區）
            🔵 藍色 = 最大量區（2355.0 元）
            🔴 紅色 = 壓力區（高於最大量區）
        - 標記線：
            藍色虛線 = 最大量區
            藍色點線 = 收盤價
        - 標題：「價格分佈成交量」
- 注意事項：
    - FinMind API 返回的 Time 欄位格式為 HH:MM:SS.ffffff（包含微秒），例如 09:00:08.099051
    - FinMind API 返回的 TickType 是字串型別（'1' 和 '2'），而不是數字
    - 檢查生成圖表內中文所需的字型是否有安裝
        下載並設定 Noto Sans TC 字型
            字型來源：Google Fonts (gstatic.com)
            檔案路徑：/workspace/packages/NotoSansTC-Regular.ttf
            格式：TTF (TrueType Font)
