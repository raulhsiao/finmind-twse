## 1. 資料取得 / Data Acquisition

**中文：**
從 FinMind API 抓取指定股票於特定交易日的逐筆交易資料（TaiwanStockPriceTick），並同時抓取日成交資訊（TaiwanStockPrice）用於資料核對。

**English：**
Fetch tick-by-tick transaction data (TaiwanStockPriceTick) for a specified stock on a specific trading date from FinMind API, and simultaneously fetch daily price data (TaiwanStockPrice) for data verification.

**參數 / Parameters：**
| 參數 / Parameter | 說明 / Description | 範例 / Example |
|-----------------|-------------------|---------------|
| stock_id | 股票代號 / Stock ticker symbol | 2330 |
| trade_date | 交易日（YYYY-MM-DD 格式）/ Trading date | 2026-06-01 |

**API 端點 / API Endpoints：**
```
GET /api/v4/data
Params:
  - dataset: "TaiwanStockPriceTick"
  - data_id: {stock_id}
  - start_date: {trade_date}
```

## 2. 尋找最近交易日 / Find Latest Trading Date

**中文：**
自動尋找最近一個有資料的交易日。如果當前時間尚未超過 15:30，則往過去找下一個交易日；如果已超過 15:30，則使用當天或最近的交易日。

**English：**
Automatically find the most recent trading date with available data. If the current time is before 15:30, search backward for the previous trading date; if after 15:30, use the current day or the nearest trading date.

**邏輯 / Logic：**
1. 抓取 TaiwanStockTradingDate 獲取交易日列表 / Fetch TaiwanStockTradingDate to get list of trading dates
2. 比較當前時間與 15:30 / Compare current time with 15:30
3. 返回合適的交易日 / Return appropriate trading date

**流程圖 / Flowchart：**
```
當前時間 < 15:30？
  ├─ 是 → 找前一個交易日 / Find previous trading date
  └─ 否 → 使用當天或最近交易日 / Use current or nearest trading date
```

## 3. VWAP 計算 / VWAP Calculation

**中文：**
計算成交量加權平均價（Volume Weighted Average Price, VWAP）。使用公式：VWAP = cumsum(成交價 × 成交量) / cumsum(成交量)

**English：**
Calculate Volume Weighted Average Price (VWAP). Using formula: VWAP = cumsum(deal_price × volume) / cumsum(volume)

**輸入欄位 / Input Fields：**
| 欄位 / Field | 說明 / Description | 型別 / Type |
|-------------|-------------------|------------|
| deal_price | 成交價 / Transaction price | float |
| volume | 成交量 / Transaction volume | int |

**公式 / Formula：**
```
VWAP = Σ(deal_price × volume) / Σ(volume)
```

**輸出 / Output：**
| 輸出 / Output | 說明 / Description |
|--------------|-------------------|
| vwap_series | 動態 VWAP 序列 / Dynamic VWAP series |
| final_vwap | 最終 VWAP 值 / Final VWAP value |

## 4. 內外盤氣勢分析 / Buy-Sell Pressure Analysis

**中文：**
分析主動買盤（外盤）與主動賣盤（內盤）的力道對比，判斷市場買賣情緒。

**English：**
Analyze the strength comparison between active buy orders (external trades) and active sell orders (internal trades) to determine market sentiment.

**TickType 分類 / TickType Classification：**
| 值 / Value | 說明 / Description | 計入內外盤 / Include |
|-----------|-------------------|---------------------|
| 2 | 主動買盤 / Active Buy | ✓ 是 / Yes |
| 1 | 主動賣盤 / Active Sell | ✓ 是 / Yes |
| 0 | 集合競價/特殊交易 / Call Auction or Special | ✗ 否 / No |

**計算方式 / Calculation：**
```
buy_volume = Σ(volume where TickType == "2")
sell_volume = Σ(volume where TickType == "1")
buy_sell_ratio = buy_volume / sell_volume
```

**信號判斷 / Signal Judgment：**
| 買/賣比率 / Ratio | 信號 / Signal | 顏色 / Color |
|------------------|-------------|-------------|
| > 1.5 | 偏多 / Bullish | 紅色 / Red |
| 1.1 ~ 1.5 | 小幅偏多 / Slightly Bullish | 紅色 / Red |
| 0.9 ~ 1.1 | 中性 / Neutral | 藍色 / Blue |
| 0.67 ~ 0.9 | 小幅偏空 / Slightly Bearish | 綠色 / Green |
| < 0.67 | 偏空 / Bearish | 綠色 / Green |

## 5. 主力大單追蹤 / Large Order Tracking

**中文：**
追蹤單筆成交量超過門檻（預設 50 張）的大單，分析主力資金流向。

**English：**
Track large orders with single transaction volume exceeding threshold (default 50 lots), analyzing institutional fund flow.

**門檻設定 / Threshold Setting：**
- 預設：50 張（50,000 股）/ Default: 50 lots (50,000 shares)

**計算方式 / Calculation：**
```
large_orders = filter(volume >= threshold)
large_buy_volume = Σ(volume where TickType == "2")
large_sell_volume = Σ(volume where TickType == "1")
large_order_ratio = large_orders_volume / total_volume × 100%
```

**信號判斷 / Signal Judgment：**
| 條件 / Condition | 信號 / Signal | 顏色 / Color |
|-----------------|-------------|-------------|
| 大單買入 > 大單賣出 × 1.5 且 買入均價 > 賣出均價 | 主力吃貨 / Accumulation | 紅色 / Red |
| 大單賣出 > 大單買入 × 1.5 且 賣出均價 < 買入均價 | 主力出貨 / Distribution | 綠色 / Green |
| 大單買入 > 大單賣出 | 買盤較強 / Buy Stronger | 紅色 / Red |
| 大單賣出 > 大單買入 | 賣盤較強 / Sell Stronger | 綠色 / Green |
| 其他 / Others | 多空膠著 / Balanced | 藍色 / Blue |

## 6. 關鍵價位分析 / Price Level Analysis

**中文：**
將成交價格分為 10 個區間，統計每個區間的累積成交量，找出最大量區、支撐位與壓力位。

**English：**
Divide transaction prices into 10 bins, calculate cumulative volume for each bin, identify maximum volume zone, support level, and resistance level.

**定義 / Definitions：**
| 名稱 / Name | 定義 / Definition |
|------------|------------------|
| 最大量區 / Maximum Volume Zone | 累積成交量最大的價格區間 / Price bin with highest cumulative volume |
| 支撐位 / Support Level | 最大量區下方的價格區間 / Price bin below maximum volume zone |
| 壓力位 / Resistance Level | 最大量區上方的價格區間 / Price bin above maximum volume zone |

**顏色標示 / Color Coding：**
| 區域 / Zone | 顏色 / Color | 意義 / Meaning |
|------------|-------------|---------------|
| 支撐區 / Support Zone | 綠色 / Green | 低於最大量區 / Below max volume |
| 最大量區 / Max Volume Zone | 藍色 / Blue | 成交量最大 / Highest volume |
| 壓力區 / Resistance Zone | 紅色 / Red | 高於最大量區 / Above max volume |

| 其他 / Others | 中性 / Neutral | 藍色 / Blue |

**收盤信號 / Closing Signal：**
| 條件 / Condition | 信號 / Signal | 隔日預測 / Next Day Prediction |

## 11. 資料正確性驗證 / Data Verification

**中文：**
比對逐筆資料與日成交資料的開盤價、收盤價、最高價、最低價、成交量，確保資料正確性。

**English：**
Compare open, close, high, low prices and volume between tick data and daily data to ensure data accuracy.

**核對項目 / Verification Items：**
| 項目 / Item | 容許誤差 / Tolerance | 狀態標記 / Status |
|------------|-------------------|------------------|
| 開盤價 / Open | < 0.01 | ✓ 或 ✗ |
| 收盤價 / Close | < 0.01 | ✓ 或 ✗ |
| 最高價 / High | < 0.01 | ✓ 或 ✗ |
| 最低價 / Low | < 0.01 | ✓ 或 ✗ |
| 成交量 / Volume | < 10% 差異 | ✓ 或 ✗ |

**注意事項 / Notes：**
- 逐筆資料可能為採樣資料，成交量可能與日成交資料有差異
- 價格應完全匹配 / Prices should match exactly

**中文：**
